# README Maintenance Rule

The `README.md` file in the root of the project is the definitive entry point for any developer interacting with PrismUI. 
It must be kept rigorously up to date.

## When to Update the README
You MUST automatically update the `README.md` whenever:
1. **New Components are added**: When a new component is successfully implemented and merged, its name/category must be added to the Component List in the README.
2. **Architecture or Stack Changes**: If a new core dependency is added, or version requirements change (e.g., Node version updates), the README must reflect it.
3. **Setup Instructions Change**: Any changes to how the project is built, run locally, or deployed must be documented immediately.

Do not wait for explicit user instruction to update the README if one of the above conditions is met during a task. It should be a standard part of your task completion workflow.
