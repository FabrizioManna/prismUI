# Creazione Spec per PrismUI

Quando ricevi una richiesta in italiano per creare una nuova feature o spec per PrismUI, segui ESATTAMENTE questa procedura:

## 1. Analizza e Rifinisci
Leggi la richiesta in italiano. Strutturala in modo logico, aggiungendo eventuali step tecnici mancanti necessari per l'implementazione nel framework (es. componenti Lit, Tailwind, ecc.).

## 2. Traduci in Inglese Tecnico
Riscrivi tutto in inglese professionale e tecnico. Il documento finale deve contenere queste sezioni:
- **Title**: Un titolo chiaro, es. `# Spec: [Titolo]`.
- **Date**: La data di oggi (YYYY-MM-DD).
- **Status**: `Draft` o `Pending`.
- **Goal**: Un riassunto ad alto livello dell'obiettivo.
- **Scope**: Un elenco numerato e dettagliato dei task da implementare.

## 3. Assegna il Numero Progressivo
Controlla i file già esistenti nella cartella `.antygravity/specs/`. Trova il numero più alto (es. `0006`) e assegna a questa nuova spec il numero successivo (es. `0007-titolo-spec.md`).

## 4. Crea il File
Genera il file markdown nella cartella `.antygravity/specs/` rispettando scrupolosamente l'impaginazione e lo stile delle altre specifiche presenti.
